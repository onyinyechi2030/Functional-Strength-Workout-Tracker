# Strength Companion v2.4

Five-day functional-strength tracker with two recovery days, equipment-based workout blocks, Primary/Accessory exercise labels, substitutions, additional exercise tracking, local-first saving, and optional Firebase sync.

## GitHub Pages
Upload all files directly to the repository root and publish from `main` / `(root)`.

## v2.4 highlights
- Saturday Thruster replaced by Double-Dumbbell Front Squat.
- Saturday Push-Up replaced by Band Lat Pulldown.
- Strength days grouped by practical equipment stations.
- Program Completion excludes optional Additional Work.
- Additional Work is tracked separately as extra sets performed.
- Primary vs Accessory labels clarify what to prioritize if time is limited.
